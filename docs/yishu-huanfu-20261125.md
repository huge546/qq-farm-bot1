## extra 配置

`2026111708.extra` 为 UTF-8 JSON（1,736 字节 base64），关键内容：

```json
{
  "uid": "YiShuHuanFuMainUI",
  "tips": { "title": "活动说明", "txt": ["..."] }
}
```

规则原文要点：

1. 活动期间领取红薯种子，种在普通农田，收获红薯时额外获得蜜薯。
2. 蜜薯可卖给自己铺子（按本人当日收购价，不限量），也可通过好友分享的铺子卡片卖给好友（按对方当日价格，占用对方每日接收额度，好友获得福气币分红）。
3. 每日首次分享自己的铺子到 QQ/微信好友或群聊，触发一次「分享暴击」涨价，每日 0 点清零。
4. 每日 24:00 由系统按本人铺子当日最终收购价自动售出全部蜜薯。
5. 奖励：盆栽·七色花弦、福气金豆礼包、实用道具。

`uid` 字段可用于识别页面，属于客户端静态标识，不是账号状态。

## 补齐方式（推荐）

用同一套 mitmproxy 链路重抓一次，按固定顺序操作，时间戳即可把请求切开：

1. 打开活动页 → 领取红薯种子
2. 点「分享」到好友或群（触发分享暴击）
3. 卖出 1 个蜜薯（不要一次全卖）
4. 兑换最低价商品一次
5. 领取任意可领奖励

每一步之间停 2~3 秒即可，回包里的 `operate_type` 与 `130` 状态变化会直接给出映射。
